# Raw Transcripts

The raw English transcripts these notes were built from — one `.txt` file per lecture day.

**How these were produced:** the original lectures were recorded in Telugu. Each file here is the direct output of local speech-to-text (Whisper, running the `translate` task), which transcribes and translates straight to English in one step — no LLM/AI involved in this step. As raw ASR output, expect run-on, unpunctuated, conversational text (classroom chatter, filler words, cross-talk included) and occasional mistranscribed technical terms.

**Where to actually read/learn from these lectures:**
- [../](../) — concise notes, one file per day.
- [../detailed-notes/](../detailed-notes/) — deep, example-rich, diagram-heavy notes per day.

These raw files are kept for reference/traceability, not meant as the primary way to consume the material.

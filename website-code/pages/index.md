# MuleSoft Course — Study Notes

Notes for the **MuleSoft Telugu course (Green Cloud batch)**: 57 class sessions (Day 1 – Day 58) and 3 interview-preparation sessions, built from the class recordings.

<div data-study="dashboard" data-cards="assets/cards.json" data-quiz="assets/quizbank.json"></div>

**A daily routine that works:** 1) open **Continue** and study the next lecture → 2) do its **Quiz** → 3) finish with **Review Today** (10–15 min) → once a week, take a **phase test** and clear **My Mistakes**.

## How each lecture is organised

| Page | Use it for |
|---|---|
| **Summary** | A 5-minute read before or after the class |
| **Detailed Notes** | Watching alongside the video — explanations and diagrams |
| **Super-Detailed Notes** | Deep revision — every point taught, terminology, interview questions with answers, *Must Remember* |
| **Slides** | The screens and drawings from the class, with their time in the video |
| **Quiz** | Checking yourself after the class — options are shuffled every time |
| **Flashcards** | Daily revision — flip, then mark *Know it* or *Again* |

The source notes, raw and cleaned transcripts live in the [GitHub repository](https://github.com/developerashok99/green-c-mule-notes).

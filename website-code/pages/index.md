## How each lecture is organised

| Page | Use it for |
|---|---|
| **Summary** | A 5-minute read before or after the class |
| **Detailed Notes** | Watching alongside the video — explanations and diagrams |
| **Super-Detailed Notes** | Deep revision — every point taught, terminology, interview questions with answers, *Must Remember* |
| **Slides** | The screens and drawings from the class, with their time in the video |
| **Quiz** | Checking yourself after the class — options are shuffled every time |
| **Flashcards** | Daily revision — flip, then mark *Know it* or *Again* |

**Shortcuts:** ++slash++ search · quizzes **1–4** / **Enter** · flashcards **Space** / **←** / **→** · bottom-right: **A− / A+** text size and **Focus** (notes only, fullscreen; **Esc** to leave).

# Cleaned Transcripts

These are cleaned-up versions (Days 3–36) of the raw Whisper transcripts in [transcripts/](../transcripts/). The raw files are left unchanged.

What was done to each day:

- Misheard technical terms corrected from context and from the class screens (for example "palm file" → pom file, "API kit rotor" → APIkit Router, "Gemato" → Zomato).
- Speech-to-text repetition loops removed.
- Punctuation and paragraphs added.
- Text read from the video added in brackets: `[screen: …]`, `[slide: …]` or `[drawing: …]`. The matching images are in [slides/](../slides/).
- Parts that could not be recovered are marked `[unclear]`. Nothing was added that the instructor did not say.

If your application is down — not running — at that point you get 503 Service Unavailable. If you observe, one more case: when your Autodiscovery is enabled, in your local Studio too you get this error. You deploy the application, the application deploys, but you don't receive a response. At that point you need to pass the parameter for the Anypoint Platform gatekeeper as disabled, or you can comment out the Autodiscovery ID — either can be done — and only then can you consume the response from the API.

Now 504 Gateway Timeout: the server acting as a gateway or proxy — you already know the gateway is there — did not receive a timely response from the upstream server. For example, in the gateway we said that for this particular request I need the response in 300 milliseconds, but the upstream server does not respond within 300. Generally, with the HTTP Request, we get an HTTP response timeout; in the same way, here it is 504 Gateway Timeout. You can configure it in the gateway too. So these are the status codes.

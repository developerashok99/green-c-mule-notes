In today's session we will first talk about the Async scope. There is a scope called Async; in it, we can run any activity in asynchronous mode. First, if we understand what synchronous is, then asynchronous is easy, because asynchronous is the opposite of synchronous.

Generally, we have an API. What do we do in the API? First we get a request, and then we send a response. Our consumer — after sending the request, are they waiting for the response? Yes. There are three or four components here: first, second … fourth. They execute in sequence. Each component processes the event; the next component waits for the previous component's response. If you observe, I sent the request to the database and I am waiting for the response from the database. We call this synchronous mode: when we send something and wait for it.

Now, there are situations where something needs to happen alongside the main process. For example, we have received a loan request.
